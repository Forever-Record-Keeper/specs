# 0014. Website address

Date: 2026-11-23

## Decision

The website starts on the GitHub Pages default address `forever-record-keeper.github.io`.
The website moves to a domain of its own later.
The repos don't name that domain before the project has registered it.

## Reason

The maintainer chose this order.
Domain resellers read public repos.
A reseller can register a domain from a repo first and offer it to the project at a higher price.

## Consequences

- The links in the repos and the docs change when the website moves to its domain.
