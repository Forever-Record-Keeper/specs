# 0022. Contributor Covenant 2.1 as the code of conduct

Date: 2026-11-23

## Decision

The code of conduct is the Contributor Covenant 2.1.
Version 3.0 uses CC BY-SA 4.0, a share-alike license.

## Reason

Share-alike terms don't fit the MIT License of the project.

## Consequences

- The project stays on version 2.1 as long as version 3.0 uses share-alike terms.
