# 0024. Only collaborators open PRs for now

Date: 2026-11-23

## Decision

Each repo accepts PRs from collaborators only.
The project opens PRs to everyone when it is ready for outside contributors.

## Reason

The maintainer decides what enters the repos while the process is new.

## Consequences

- People outside the project can't open PRs yet.
- A later record opens the repos to outside PRs (see 0018).
