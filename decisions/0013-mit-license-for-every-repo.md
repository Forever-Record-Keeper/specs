# 0013. MIT License for every repo

Date: 2026-11-23

## Decision

Every repo of the project uses the MIT License.
Each contribution uses the license of its repo.

## Reason

The maintainer chose the license for the product.

## Consequences

- Anyone can reuse the code, also in closed products, if they keep the license notice.
- Texts that the project takes from others must have terms that fit the MIT License (see 0022).
