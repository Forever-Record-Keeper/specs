# 0018. No sign-off for now

- Status: accepted
- Date: 2026-11-23

## Decision

Commits need no Developer Certificate of Origin sign-off.
The project adds the sign-off when outside contributors arrive.

## Reason

Only collaborators can open PRs (see 0024).
The sign-off matters when people outside the project contribute.

## Consequences

- Commits have no `Signed-off-by` line.
